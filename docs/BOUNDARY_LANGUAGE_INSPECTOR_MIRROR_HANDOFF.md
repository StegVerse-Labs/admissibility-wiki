## Evidentiary ceiling rule

The ceiling is an evidentiary ceiling rather than an arbitrary restriction. It should extend to the full capability of the established artifacts:

```text
claim everything the evidence can carry;
claim nothing the evidence cannot carry.
```

A conservative review posture must not suppress conclusions that the artifacts genuinely establish. It must instead identify the highest validation level actually supported and preserve every unsupported higher-level conclusion as unresolved.

## Public validation levels

The external-framework review process explicitly distinguishes:

```text
Level 1: replayability
Level 2: reconstructability
Level 3: full reality reformulation
```

These levels are cumulative only when the evidence supports each level. A result at one level must not be represented as satisfying a higher level, and a lower-level label must not be used to conceal stronger artifact capability.
