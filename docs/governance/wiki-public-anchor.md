# Wiki Public Anchor

The StegVerse Wiki network is intended to become a recognized public anchor for governed external-framework review, capability mapping, evidence preservation, independent reconstruction, dispute handling, and public determinations.

## Constitutional Position

The Wiki is a public anchor, not an unquestionable narrator.

No determination possesses standing merely because StegVerse published it. Standing exists only to the extent that the supporting evidence, historical state, test method, decision rule, uncertainty, and challenge path can be independently inspected and reconstructed.

```text
publication != truth
visibility != authority
certification != execution authority
current state != historical state at time T
StegVerse determination != immunity from reciprocal review
```

## Public-Anchor Chain

```text
framework declaration
  -> evidence registration
  -> version and time-T binding
  -> parameterized test
  -> bounded determination
  -> public review docket
  -> independent reconstruction
  -> challenge or confirmation
  -> correction, supersession, or current standing
```

Every material conclusion should occupy an identifiable position in this chain.

## Required Views

Each mature framework docket should expose:

1. framework-native declaration;
2. StegVerse-derived boundary;
3. capability matrix;
4. evidence registry;
5. parameterized test history;
6. bounded determination;
7. framework response and dispute history;
8. independent reconstruction results;
9. corrections and supersession history;
10. current standing;
11. machine-readable review record;
12. public verification instructions.

## Time-T Reconstruction

A determination must be bound to the state relevant when it was made or when consequence attached.

```text
framework identity at T
code and configuration at T
policy and delegation at T
evidence admitted at T
review and test profile at T
environmental boundary at T
recorded determination at T
```

Later policy, ontology, model, or implementation changes must not be projected backward without an explicit superseding review.

## Symmetrical Scrutiny

Any framework, reviewer, government body, researcher, or AI entity may examine the same governed record and publish a reconstruction result.

A disagreement is not erased. It becomes a governed review event identifying:

- the evidence or state difference;
- the rule or implementation difference;
- the resulting determination delta;
- the requested correction or standing change;
- the disposition and receipt.

StegVerse frameworks are subject to standards equal to or stricter than those applied to external frameworks.

## Protected Evidence

Universal challengeability does not require unrestricted disclosure.

A docket may distinguish:

- public evidence;
- authorized protected evidence;
- derived or zero-knowledge verification;
- withheld evidence whose absence limits standing.

A hidden artifact may support only the standing that independent governed reviewers are permitted and able to reconstruct.

## Recognition Path

Recognition should emerge from disciplined use:

```text
usefulness
  -> reliability
  -> repeated independent verification
  -> institutional reliance
  -> procurement or regulatory recognition
```

Government recognition attaches legal or procurement consequence to a governed review process. It does not make StegVerse epistemically infallible.

## Canonical Machine Record

Each public docket should be backed by a record conforming to:

```text
static/schemas/governed-framework-review.schema.json
```

The human-readable Wiki page is a projection of that governed record and its linked evidence, not the sole source of truth.

## Public Determination Rule

A public determination must state:

- framework and version;
- review time and relevant historical time;
- evidence set;
- test profile;
- observed result;
- uncertainty and exclusions;
- challenge status;
- reconstruction status;
- current standing;
- supersession state.

## Non-Claims

```text
The Wiki does not become authoritative merely by publishing a page.
The Wiki does not grant execution authority.
A framework page is not a timeless judgment of every version or deployment.
An unresolved claim is not a failed or disproven claim.
A reproduced test is not general certification beyond its stated scope.
```

## Activation Target

The first activation target is one complete external-framework review docket rendered from a valid machine-readable record, with evidence references, time-T binding, parameterized tests, challenge handling, reconstruction instructions, and supersession controls.
