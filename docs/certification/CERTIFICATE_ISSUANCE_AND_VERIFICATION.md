# Certificate Issuance and Verification

## Purpose

This contract implements the issuance gate for Governance-Chain Certification without conflating a working certificate pipeline with activation of a public certification authority.

## Issuance preconditions

A certificate may be generated only when all of the following are true:

```text
candidate schema valid
subject/version immutable binding present
selected certification profile exists
all required properties have observed results
all required negative controls executed
required evidence packet fields present
all evidence hashes resolve to retained artifacts
validator result = PASS
no required evidence state = UNOBSERVED
no required property = INDETERMINATE
no lifecycle blocker = EXPIRED | SUSPENDED | REVOKED | SUPERSEDED
commercial relationship does not alter disposition
```

If any precondition is false, issuance MUST fail closed and no `CERTIFIED` certificate may be emitted.

## Certificate classes

```text
REFERENCE_CERTIFICATE
  proves the issuance and verification machinery against a deterministic internal reference candidate
  MUST carry public_claim_allowed=false
  MUST NOT be represented as an external certification

EXTERNAL_CERTIFICATE
  may be generated only for an evidence-complete external subject under the canonical certification standard
  public use still depends on public-authority activation state
```

## Verification

Independent verification MUST recompute or validate:

```text
certificate schema
candidate identity and immutable subject binding
test profile identity/version
certified property set
negative-control coverage
evidence packet hash
certificate canonical hash
lifecycle state
public-claim eligibility
authority-effect = NONE
```

Verification of a certificate does not grant execution authority, governance authority, custody, endorsement, or legal approval.

## Fail-closed negative cases

The issuance validator MUST reject at least:

```text
missing evidence
unobserved required negative control
subject version mismatch
certificate/evidence hash mismatch
property result outside profile scope
INDETERMINATE required property
expired or revoked lifecycle state
attempted public claim from REFERENCE_CERTIFICATE
attempted outcome purchase flag
```

## Reference issuance gate

The first certificate generated by this lane is a deterministic `REFERENCE_CERTIFICATE` for the Governance-Chain Certification fail-closed reference mechanism itself. Its role is to demonstrate:

```text
candidate -> evidence -> bounded property result -> certificate -> independent verification
```

The reference certificate does not certify StegVerse as a whole, does not certify any external framework, and cannot activate a public certification program.

## Activation decision states

```text
PIPELINE_INCOMPLETE
PIPELINE_OPERATIONAL_REFERENCE_ONLY
PUBLIC_AUTHORITY_ELIGIBLE_FOR_DECISION
PUBLIC_AUTHORITY_ACTIVE
PUBLIC_AUTHORITY_INACTIVE
```

For this goal, `PIPELINE_OPERATIONAL_REFERENCE_ONLY` is a valid successful terminal state if the machinery is complete but no external evidence-complete certification has been observed.
